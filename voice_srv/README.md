Для работы необходима библиотека Vosk. Файлы можно найти в релизах репозитория самой библиотеки https://github.com/alphacep/vosk-api/releases
#Подключение библиотеки к проекту
Если используется Microsoft Visual Studio, то необходимо зайти в свойства проекта, в разделе "Компоновщик->Ввод" в пункте "дополнительные зависимости" указать место хранения файла с расширением .lib, в разделе "C/C++->Общие" в "Дополнительные каталоги включаем" указать место хранения файлов библиотеки.
Если используется VS Code, путь к .lib необходимо указать для пункта "args" в файле tasks.json
#Использование
Для использования необходимо создать новый объект класса voice.
Если не указывать параметры, будет использоваться по умолчанию модель с русским язвком.
Если указать числовой параметр, можно будет выбрать другую модель. 1 - английский, 2 - русский. По умолчанию, если указать другое число, используется русский.
Функция convertAudio выявляет текст из аудиофайла.
На входе принимается параметр типа const char* - путь к самому аудиофайлу. Этот тип можно получить из string при помощи встроенной функции c_str()
На выходе функция даёт строку, содержащую всё, что Vosk смог распознать из аудиофайла. (т.е., если из файла библиотека успешно распознала фразу "this is a template", то функция вернёт строку со значением "this is a template")
