Проект выполняется в среде Unreal Engine 5.5

В рабочее пространство добавляются объекты классов Voice_Capture и EmptyPawn.

При нажатии и удержании ЛКМ происходит захват звука с устройства ввода по умолчанию и запись его в WAV файл для дальнейшей обработки.
При нажатии и удержании E звук так же записывается в файл, дополнительным параметром передавая id персонажа.

При отпускании любой из этих кнопок, WAV файл отправляется на распознавание, и результат его обработки выводится в debug messege в консоли среды.
